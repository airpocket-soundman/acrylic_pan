# 保存済みODL重み

展示ホストの `~/.acrylic_pan/calibrations` から取得した名前付き重みプロファイル7件。
元のID・名前・保存日時・学習方式・回数を保持している。
各JSONには32×60のbfloat16 β重み、工場モデルCRC、重みCRCを含む。
取り込み時に全件の重みサイズとCRCを検証済み。

展示ページの「追加学習」→「重みファイルを選んで読み込む」でJSONを選択すると、
展示ホストへ保存したうえでボードへ復元する。工場モデルCRCが一致するファームが必要。
これらは学習後の重みであり、打撃の生波形や学習途中のP行列は含まない。

運用中に新しく保存したプロファイルはホストの保存領域に作成される。
このディレクトリへのバックアップは取得時点のスナップショットである。
