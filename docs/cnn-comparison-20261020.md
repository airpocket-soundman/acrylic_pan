# CNN、PC版MLP、Solist-AI ELMの比較(2点支持の5セッション)

1次元CNNを作り、PC版のMLPと、ボードに載せているSolist-AIのELMと、同じデータ・同じ評価で比べた。

- スクリプト: `sim/compare_cnn_mlp_elm.py`(PyTorchが要る。`requirements.txt` には入れていない)
- 実行: `python -m sim.compare_cnn_mlp_elm --sessions-root data/raw/sessions_2point --loso`
- 結果: `artifacts/cnn_comparison/results.json`

## 条件

- データ: 2点支持の5セッション、3,600打、60測定点(センター2セッション、四隅3セッション)
- 同一セッション内の評価: 反復番号が5の倍数の720打を評価に使い、残りの2,880打で学習(デバイスとPCの学習と同じ規則)
- 別セッションでの評価(LOSO): 1セッションを丸ごと外して、残りの4セッションで学習し、外したセッションで評価。5回の平均は、打数で重みを付けた
- 指標: 60測定点の正解率(Top-1)。CNN、時系列MLP、同じ形のMLPは、3つの初期値(1、7、21)で学習して平均した
- 入力:
  - ELM: トリガ後448点から取り出した127点(+バイアス入力1)。ピークで正規化して標準化
  - PC版MLP: 714特徴(時系列448点、周波数成分256個、統計10値)
  - CNNと時系列MLP: トリガ後448点を、ピークで正規化しただけの波形(周波数成分も統計も使わない)
  - 同じ形のMLP: ELMと同じ、トリガ後448点から取り出した127点(+バイアス入力1)。入力側の重みも学習する
- ELMは正解ラベルだけで学習した(蒸留なし)。PC版MLPは、実機用の学習と同じ3モデルのアンサンブル

## 読み取れること

- 同じ分割で比べると、ELMの97.92%は、PC版MLPの99.17%より1.25ポイント低い。別セッションでは、93.6%と97.7%で、差は4.1ポイントに開く。
- CNNは、最小のCNN-XS(7,116パラメータ)でも、同一セッション内で99.49%、別セッションで98.5%となり、ELMとPC版MLPのどちらも上回った。CNN-XSのパラメータ数は、ELMの1.2倍である。
- 同じ時系列448点を入力にしたとき、MLP(98.98% / 97.0%)よりCNN(99.49〜99.54% / 98.5〜99.1%)の方が高かった。PC版MLPは、周波数成分と統計を加えた714特徴で、時系列だけのMLPより少し高い(99.17% / 97.7%)。
- ELMと同じ形(128-32-60)・同じ入力で、入力側の重みも学習したMLP(6,108パラメータ)は、同一セッション内で99.17%、別セッションで97.6%となり、PC版MLP(約112万パラメータ)と同じ水準だった。ELMとの差は、入力側の重みを固定したことによる約1.3ポイント(同一セッション内)である。ELMが学習するのは出力側のβ(1,920個)だけで、この同じ形のMLPの約1/3である。
- 3つの初期値の間の差は、CNN-XSで同一セッション内の99.17〜99.72%と、小さくはない。CNN-Sは99.44〜99.58%、CNN-Lは99.44〜99.58%だった。
- 同一セッション内の評価は、同じ収録の別の打撃を評価に使うので、別セッションの評価より、高く出る。

## 限界

- CNNのハイパーパラメータ(層の数、カーネル幅など)は、3種類を固定して試しただけで、調整していない。
- 評価は、1台の板、2点支持、同じ打撃者の5セッションに限る。別日・固定し直し・別打撃者への評価ではない。
- CNNは、PC上のPyTorchで評価した。Solist-AI(AxlCORE-ODL)への実装と、実機での評価は、していない。ボードに載せている構造は、入力側を固定した隠れ層1層のELMである。
