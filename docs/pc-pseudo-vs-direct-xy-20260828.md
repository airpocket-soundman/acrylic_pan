# PC版 疑似XY回帰と直接XY回帰の比較（2026-08-28整理）

## 用語

- **直接XY回帰**: 波形特徴からX、Yの2値をモデルが直接出力する。
- **疑似XY回帰**: 60測定位置をクラス分類し、60クラス確率と各クラスの代表座標の加重平均から期待座標を算出する。

MCU版は、固定Alpha・隠れ32・Betaのみ学習可能という制約では直接XY回帰の表現力が不足したため、60クラス確率分類から期待座標を求める疑似XY回帰を採用している。

## PC版の比較条件

既存の次の評価ログを比較した。両ログのデータセットSHA-256は
`046c7bdf15dec5d5d543a822bad7e40d8144522d0b59687668e46dba875bc37c`で一致する。

- 全データ: 11セッション、7,132打点、60測定座標
- 評価データ: 測定回数を5で割った余りが0の1,426件
- 入力: 714特徴
- 隠れ層: 384、192、96
- 初期値: 1、7、21の3モデルアンサンブル
- 直接XY回帰: `714-384-192-96-2`、1モデル367,202パラメータ
- 60クラス分類: `714-384-192-96-60`、1モデル372,828パラメータ

60クラスモデルは位置ごとの学習件数を均衡化しているため、元の学習イベントは5,706件だが、学習時のbalanced countは9,600件である。評価用1,426件は共通である。

## 結果

| 指標 | 直接XY回帰 | 60クラス確率からの疑似XY回帰 |
|---|---:|---:|
| 平均距離誤差 | 5.42 mm | **1.81 mm** |
| 中央値 | 3.42 mm | **0.11 mm** |
| 90%点 | 9.50 mm | 未記録 |
| 25 mm以内 | 98.53% | 未記録 |
| 50 mm以内 | 99.30% | 未記録 |
| 12エリア精度（期待座標から変換） | **99.30%** | 99.16% |
| 60測定点Top-1精度 | 該当なし | 98.88% |
| 最尤60点の平均距離 | 該当なし | 1.13 mm |

## 解釈

既知の60測定点上では、60クラス方式が距離誤差で有利だった。正しいクラスを高確率で選べば、そのクラスの代表座標は正解座標そのものなので誤差がほぼ0になるためである。中央値0.11 mmは連続空間を0.11 mm精度で回帰できたことを意味しない。

直接XY回帰は既知点でも常に連続値を生成するため、小さな回帰誤差が残る。一方、12エリア境界で評価すると直接XY回帰99.30%、疑似XY回帰99.16%でほぼ同等だった。

この比較だけでは、学習していない中間座標に対する性能は判断できない。真の連続座標性能を比較するには、60測定点とは異なる中間座標を評価専用に収録し、再学習せず両モデルへ入力する必要がある。
