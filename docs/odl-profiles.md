# 展示ホストでのODL重み保存

展示ページの「追加学習」に、戻る操作と重みプロファイルを追加した。
学習中の「一つ前へ戻る」は繰り返し使用でき、現在の学習セッションの先頭まで戻れる。
ファームは入力と教師ラベルをFRAMへ記録し、開始時の重みから残った履歴を再学習する。
1セッションの履歴上限は500打。展示UIは高速60打、精密300打である。
開始前に保存した重みは、取り消しや中止で変更されない。

「現在の重みをこの端末に保存」はボードでコミット済みのβを読み出す。
保存先は展示サーバーを動かすOSユーザーの `~/.acrylic_pan/calibrations`。
WindowsでもRaspberry Piでも同じPythonコードを使用し、ホスト再起動後もファイルは残る。
環境変数 `APAN_CALIBRATION_DIR` で保存先を指定できる。
Raspberry Piのサービスは同じユーザー・永続ディスクの保存先で起動すること。

ファイルには名前、日時、方式、打撃数、モデルCRC、βとそのCRCを記録する。
一時ファイルへの書込み、fsync、置換で保存し、読出し時にCRCを検証する。
復元時はモデルCRCを確認して32行をステージング領域へ転送し、全体CRCを照合して
FRAM保存枠へ反映する。復元したβはボード電源再投入後も残る。
継続学習はβと打撃数を引き継ぎ、Pは現行仕様どおりP0から開始する。
サーバーの保存はβプロファイルであり、途中の学習履歴やPのチェックポイントではない。
