# 展示会用ページ（4ページ構成）

発表スライド（`web/presentation/`）とは別に、展示会向けに操作を絞った4ページを `pc/acrylic_pan_web/static/exhibit/` に置く。サーバは既存のWebサーバ（`python -m pc.acrylic_pan_web`）で、同じAPIを使う。

推論系は、加速度センサを接続したML63Q2557上のSolist-AIが、単一の60出力モデルで実行する。高速／精密ODLもMCU上で行い、USBシリアルで結果をRaspberry Piへ送る。Raspberry Pi側はWeb UI、発音、USBカメラ映像、デモ動画を担当する。12エリア表示は、受信した60位置確率をエリアごとに合計した結果である。

| ページ | URL | 内容 |
| --- | --- | --- |
| 演奏 | `/exhibit/play.html` | 確率演奏ページを `?kiosk=1` で表示する。発表スライドと同じ構成（座標ヒートマップなし、12エリア確率＋カメラ枠）で、ウィンドウにぴったり収まりスクロールしない。センサ基板に接続できれば自動で演奏開始する。COMポートや校正の操作部は隠す。 |
| 追加学習 | `/exhibit/odl.html` | 高速（12エリア中心）／精密（60地点）を選び、叩く位置を板の図で示しながら5周学習する。 |
| デモ動画 | `/exhibit/video.html` | 動画フォルダの mp4 を再生する。既定は `web/assets/pv/`。複数あれば右側に一覧を出す。 |
| 管理 | `/exhibit/admin.html` | センサ基板、ファームウェア、USBシリアル、音、動画、空き容量、自動起動などを自動検査する。Web UI再起動、ラズパイ再起動、安全な電源断も行える。 |

演奏ページのカメラ枠は、カメラがOFFの間は定型の4×3のマス目を表示し、その上にエフェクトを出す。「カメラ開始」を押すと映像に切り替わり、デモと同じく「8点フィット」で枠を手動で合わせる。カメラを停止すると定型のマス目に戻る。

## 追加学習ページの操作

- **追加学習（さらに5周）**: 保存済みの校正の続きから5周学習する。保存済みの方式と選択中の方式が同じときだけ押せる。
- **新たに5周を取り直す**: 工場モデルから5周学習し、保存済みの校正を置き換える。
- **初期モデルに戻す**: 保存済みの校正を消して工場モデルに戻す。誤操作防止に2回押す。
- 学習中は他ページへの移動を止める。「中止」で保存せずに終了する。

ファームウェアへは校正開始（`CALIBRATION BEGIN`）の引数で伝える。下位4bitが方式（0 = quick、1 = precise）、bit4（`0x10`）が「保存済みβから続ける」。保存済みの方式が違う、または保存がないときはファームウェアが開始を拒否する。Web APIでは `POST /api/calibration/begin` の `{"kind": "quick"|"precise", "continue": true}`。

## 管理ページの操作

- **自動検査**: 管理ページを開いた時点で1回実行され、「自動検査を実行」で再検査できる。赤色の必須項目があれば展示前に修正する。黄色は展示を止めない注意項目で、Tailscale、Codex、カメラなど未使用の任意機能もここに含まれる。
- **検査を実行するタイミング**: 演奏・追加学習・収録中はファームウェアの単一コマンド枠と競合しないよう、`HELLO` / `STATUS` の能動照会を省略して直近の受信状態を表示する。演奏は停止しない。完全な往復検査は演奏を停止して再検査する。追加学習または収録中はシステム操作も無効になる。
- **KX134入力確認**: 管理画面を開く前に板を1回叩く。正常に解析できた実打の60位置推論だけを記録し、固定入力のAI自己診断結果はセンサ合格に数えない。KX134にはこの構成で安全に呼べる独立した自己診断コマンドがないため、最近の実打がない場合は故障扱いではなく黄色で再打撃を案内する。
- **Web UIを再起動**: `acrylic-pan-exhibit` サービスだけを再起動し、自動で再接続する。
- **ラズパイを再起動／電源を切る**: ボタンを3秒間長押しして実行する。電源断時は画面の案内に従い、アクセスLEDの点滅が止まるまで電源ケーブルを抜かない。

状態変更APIはlocalhostからの要求と管理ページで取得したセッションnonceを要求する。OS操作は任意のシェルコマンドを受け付けず、インストール時にroot所有で配置した3個の固定ヘルパーだけを`sudo -n`で実行する。管理ページ自体は通常の展示ナビゲーションに表示されるため、来場者が操作できない配置にするか、説明員が監視する。

## サーバ側の追加

- `--auto-connect [PORT]`: 基板へ自動接続し、切断されても再接続する。PORT省略時は見つかったポートを順に試す。
- `--video-dir DIR`: 動画フォルダ。`GET /exhibit-media/<name>`（Range対応）と `GET /api/exhibit/videos`。
- 展示配信は `pc/acrylic_pan_web/exhibit.py`、管理診断と固定システム操作は `pc/acrylic_pan_web/admin.py`。
