# Acrylic Pan 設計メモ

## 1. 推論問題

打撃の有無と位置推定は分ける。常時座標回帰を動かすのではなく、しきい値処理で打撃イベントを
切り出し、イベントごとに Solist-AI を1回実行する。

```text
加速度Z → 打撃検出 → 1打分の特徴量 → Solist-AI → 12エリアのスコア
                                                    ├→ 最大値 → エリア → 音階
                                                    ├→ スコア → ヒートマップ
                                                    └→ エリア中心 → 表示座標
```

より細かい位置が必要な場合は、60座標（各エリアの中心と四隅）の条件付き確率を出す
位置確率モデルを使い、確率の期待値から連続座標を求める。どちらのモデルも、
単一センサ波形に残る位置固有の振動モードの違いを手掛かりにする。

設置し直すと振動の伝わり方が変わるため、12エリア分類は設置後に数十打で
ボード上の追加学習（現場キャリブレーション）を行えるようにする。

## 2. ハードウェア前提

| 項目 | 内容 |
|---|---|
| パネル | 400 × 300 × 5 mm アクリル（現行）。初期試作は 400 × 200 × 3 mm |
| MCU/AI | ML63Q2557 + AxlCORE-ODL（DT-EBML63Q2557） |
| センサ | KX134-1211、Z軸、±32 g、別体MEMS基板を1個使用 |
| 取得周波数 | 25.6 kHz（39.0625 µs/点、KX134-1211の最大ODR） |
| 推論窓 | 20 ms、プリトリガ2.5 msを含む512点 |
| 収録窓 | 80 ms、プリトリガ2.5 msを含む2,048点 |
| 記憶域 | FRAM 256 KB（現場キャリブレーション用） |

センサの固定条件は振動伝達そのものを変えるため、固定方法を決めてから学習データを収録する。
パネル支持位置、ゴム足、ネジ締結、筐体との接触も同様に固定する。
センサはパネル中央に置く。アクリルを挟み込む固定具で
`x=200～300 mm、y=0～20 mm` の100 × 20 mm面を固定し、境界条件を非対称にして
左右鏡像点のモード強度に差を作る。

## 3. 教師データ

収録は Web UI の学習データ採取画面で、光ったエリアと打点を順に叩く誘導方式で行う。
各イベントには次を保存する（形式は [データ配置](../data/README.md)）。

- 収録セッションID、パネル仕様（`panel_profile_id`）
- エリア番号（`class_id`）、打点名、目標座標 `target_x_mm`・`target_y_mm`、反復番号
- 2,048点のZ軸生波形、サンプルレート、トリガ位置

打点は2系統とする。

- 中心（`center`）: 各100 mm角エリアの中心
- 四隅（`corners`）: 各エリア中心から (±25, ±25) mm の4点。
  固定具直下にかかる (225, 25) と (275, 25) は (225, 35) と (275, 35) へ移す

400 × 300 × 5 mm板では、中心4セッション2,345件と四隅7セッション4,787件の計7,132件を収録した。
打具はマレットとする。学習と評価は打撃単位のランダム分割ではなく、収録セッション単位
（leave-one-session-out）または反復番号で固定したholdoutで分け、同じ打撃が学習と評価に
またがらないようにする。

## 4. 特徴量

配備中の特徴量は、トリガ後448点から等間隔に取り出した128点の時間波形である。

1. プリトリガ64点の平均を差し引く。
2. トリガ後の絶対値最大で割って振幅を正規化する。
3. 128点を取り出し、学習データの平均・標準偏差で標準化する。

振幅の正規化により打撃強度への依存を抑える。FFT帯域強度、間引き、入力点数は
[サンプリング周波数比較](sampling-experiment-20260718.md)などで比較した。ハードウェアFFTの
スケーリングをPCで完全に再現できる時間波形を採用し、PC・CSV・MCUで同じ入力になるようにした。

## 5. Solist-AIモデル

| 項目 | 12エリア分類 | 位置確率 |
|---|---|---|
| 構成 | 入力128・隠れ32・出力12 | 入力128・隠れ32・出力12 × 5ヘッド |
| 活性化 | hard sigmoid | hard sigmoid |
| 教師 | one-hot | PCの確率モデルから蒸留した60座標のロジット |
| 出力 | argmax をエリアとする | 温度0.05の softmax で60座標の確率 |

- α は公式 Simulator の seed-1 射影に固定し、β だけを学習する。
- β は PC でリッジ回帰（L2 = 1）により学習し、bfloat16 でファームウェアへ組み込む。
- 12エリア分類の β は、ボード上の OS-ELM で現場の打撃から追加学習できる。
  校正1打を工場データ30打分の重みとし、CPU の float32 で更新する。

PCでは制約のない MLP による座標推定も行い、デバイスで到達できる精度との差を把握する
（[PC側・確率分布型位置推定](position-inference.md)）。

## 6. 評価指標

- 12エリア正解率、エリア別の再現率と混同行列
- 中心打点と四隅打点それぞれの正解率
- 座標推定の距離誤差（平均・中央値・90／95パーセンタイル）、25 mm・50 mm以内の割合
- 未知セッションでの精度（leave-one-session-out）
- 推論レイテンシ、RAM・Flash使用量

各モデルの評価結果は [開発ドキュメント目次](README.md) の実験記録にまとめる。

## 7. 音と表示

MCU は推論結果を UART で PC へ送り、PC のブラウザが低遅延に音を鳴らす。
12エリアには既定で C4〜G5 の12音を割り当て、割り当てはプロファイルとして保存・切り替えできる。
楽器モードではファームウェアが再トリガを抑止し、1回の結果が1回の発音に対応する。

60座標確率の楽器画面では、最新の打撃の確率分布をヒートマップとしてパネル上に描画し、
USBカメラ映像へ重ねて表示することもできる。
ボードのLCDには推定エリアの中心座標と推論時間を表示する。
